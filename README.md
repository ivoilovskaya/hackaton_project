# Поступашки: Marketing Measurement System

Проект команды для кейс-чемпионата по аналитике данных. Цель - предложить систему, которая связывает рекламное размещение, переход пользователя и оплату, а затем рассчитывает ROMI.

## Структура проекта

```text
postupashki-hackathon/
├── README.md
├── requirements.txt
├── data/
│   ├── raw/
│   │   └── base.xlsx
│   ├── processed/
│   └── mock/
├── notebooks/
│   └── sales_analysis.ipynb
├── src/
│   └── app.py
└── outputs/
    └── charts/
```

## Что хранится в папках

| Путь | Содержание |
|---|---|
| `README.md` | Описание проекта и инструкция по запуску. |
| `requirements.txt` | Список используемых Python-библиотек. |
| `data/raw/` | Исходные данные из кейса без изменений. |
| `data/processed/` | Очищенные и подготовленные для анализа таблицы. |
| `data/mock/` | Тестовые (synthetic/mock) данные для демонстрации MVP: размещения, переходы и оплаты. |
| `notebooks/` | Анализ продаж, расчёты и графики. |
| `src/` | Исходный код MVP. |
| `outputs/charts/` | Готовые графики для презентации. |

## Правила работы с данными

- Не изменять файлы в `data/raw/`.
- Явно помечать тестовые данные как `mock` или `synthetic`.
- Не добавлять персональные данные пользователей.
- Все итоговые выводы должны отделять факты от предположений.

## Минимальный MVP

Реестр рекламных размещений → уникальная ссылка → переход → оплата → расчёт ROMI.
